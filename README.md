⚡ AsyncDo — асинхронный менеджер задач
Современный высокопроизводительный таск-менеджер на FastAPI и SQLAlchemy 2.0 в полностью асинхронном режиме. Демонстрирует полный цикл fullstack-разработки: от проектирования async-БД и REST API до создания интерактивного интерфейса на чистом JavaScript без фреймворков.

Возможности
Backend

100% Async — FastAPI + async SQLAlchemy + asyncio

Аутентификация пользователей — регистрация и вход с salted-хешированием паролей

Полный CRUD — создание, чтение, обновление и удаление задач

Массовые действия — очистка всех выполненных задач одним кликом

Подтверждение задачи — отметка как выполненной без удаления

Frontend

Поиск в реальном времени — фильтрация задач по заголовку с подсветкой совпадений

Фильтрация задач — все, активные, выполненные

Сортировка — сначала новые или сначала старые

Inline-редактирование — изменение заголовка прямо в списке

Тёмная тема — переключение с сохранением настройки в localStorage

Плавные анимации — slide in/out при изменениях задач

Счётчик задач — живой подсчёт активных, выполненных и всего

Без фреймворков — чистые HTML, CSS и JavaScript

API
Задачи: 
GET /api/tasks
 — все задачи пользователя, POST /api/tasks — создание, PATCH /api/tasks/{id} — обновление, PATCH /api/tasks/{id}/confirm — отметка выполненной, DELETE /api/tasks/{id} — удаление, 
DELETE /api/tasks/completed
 — очистка выполненных.

Пользователи: 
POST /api/users/register
 — регистрация, POST /api/users/login — вход и получение ID пользователя.
